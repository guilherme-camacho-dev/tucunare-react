O Tucunaré é uma aplicação web desenvolvida em React para funcionar como uma central de conteúdo. A aplicação permite que o usuário cadastre, visualize, pesquise e exclua conteúdos.

Os dados cadastrados são armazenados no navegador utilizando localStorage, permitindo que as informações continuem disponíveis mesmo após o fechamento ou atualização da página.

O projeto foi desenvolvido utilizando componentes funcionais e a estrutura de pai para filho, seguindo os conceitos apresentados durante as aulas de React.

 - Tecnologias utilizadas

- React
- JavaScript
- HTML
- CSS
- Vite
- LocalStorage
- Git
- GitHub
- Vercel

 - Funcionalidades

- Cadastro de conteúdos;
- Visualização dos conteúdos cadastrados;
- Pesquisa de conteúdos;
- Exclusão de conteúdos;
- Persistência dos dados utilizando localStorage;
- Geração de identificadores utilizando Math.random() e Math.floor();
- Geração de notas de relevância utilizando Math.round();
- Interface responsiva para diferentes tamanhos de tela.

 - Estrutura de componentes

A aplicação utiliza componentes funcionais organizados em uma estrutura de pai para filho.
